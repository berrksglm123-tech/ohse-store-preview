1. ÇEREZ NEDİR?

Çerezler (cookies), web sitemizi ziyaret ettiğinizde tarayıcınız tarafından bilgisayarınıza veya mobil cihazınıza kaydedilen küçük metin dosyalarıdır. Bu dosyalar, web sitesinin düzgün çalışmasını sağlar ve kullanıcı deneyimini iyileştirir.

2. ÇEREZ TÜRLERİ

Web sitemizde aşağıdaki çerez türlerini kullanıyoruz:

2.1. Zorunlu Çerezler

Web sitesinin temel işlevlerini yerine getirmesi için gereklidir. Bu çerezler olmadan site düzgün çalışmaz.

  • —Oturum yönetimi çerezleri
  • —Güvenlik çerezleri
  • —Sepet bilgileri

2.2. Performans Çerezleri

Web sitesinin performansını analiz etmek ve kullanıcı deneyimini iyileştirmek için kullanılır.

  • —Google Analytics çerezleri
  • —Sayfa görüntüleme istatistikleri
  • —Kullanıcı davranış analizi

2.3. Fonksiyonel Çerezler

Web sitesinin gelişmiş işlevlerini sağlamak için kullanılır.

  • —Dil tercihleri
  • —Kullanıcı tercihleri
  • —Oturum bilgileri

2.4. Reklam Çerezleri

Size daha uygun reklamlar göstermek ve reklam kampanyalarının etkinliğini ölçmek için kullanılır (izin verdiğiniz takdirde).

4. ÇEREZ YÖNETİMİ

4.1. Tarayıcı Ayarları

Çerezleri tarayıcı ayarlarınızdan yönetebilir veya engelleyebilirsiniz. Ancak çerezleri engellemek, web sitesinin bazı işlevlerinin çalışmamasına neden olabilir.

4.2. Çerez Tercihleri

Web sitemizi ziyaret ettiğinizde, çerez tercihlerinizi seçebilirsiniz. Zorunlu çerezler dışındaki çerezleri kabul etmeme hakkınız bulunmaktadır.

5. ÜÇÜNCÜ TARAF ÇEREZLERİ

Web sitemizde, hizmet kalitesini artırmak için aşağıdaki üçüncü taraf hizmetleri kullanılmaktadır:

  • —Google Analytics: Web sitesi trafik analizi için kullanılır
  • —Ödeme Sağlayıcıları: Güvenli ödeme işlemleri için gerekli çerezler
  • —Sosyal Medya: Sosyal medya paylaşım özellikleri için (sadece kullanıldığında)

6. ÇEREZLERİN SİLİNMESİ

Çerezleri istediğiniz zaman tarayıcı ayarlarınızdan silebilirsiniz. Çerez silme işlemi hakkında detaylı bilgi için tarayıcınızın yardım bölümüne bakabilirsiniz.

7. DEĞİŞİKLİKLER

Bu Çerez Politikası, gerektiğinde güncellenebilir. Önemli değişiklikler durumunda web sitemizde duyurulacaktır.
